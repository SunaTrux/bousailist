# わが家の防災リスト

0次・1次・2次の備えとなる防災用品と保管場所を管理する、家族向けの防災チェックリストです。
インストール不要のWebアプリ(PWA)で、スマホのホーム画面に追加するとアプリのように使えます。

## できること

- **0次(持ち歩き用)/ 1次(持ち出し品)/ 2次(備蓄用)** の3つのリストをタブで切り替え
- 用品ごとにチェックと保管場所(複数選択可)を管理。保管場所ごとの一覧表示も可能
- 次ごとに保管場所の追加・削除、説明文の編集ができる
- ライト/ダークテーマの切り替え(設定画面)
- オフラインでも動作

## データの保存と共有

データは **この端末のブラウザ内にだけ** 保存されます(サーバーには送信しません)。
家族で共有するときは、設定画面の「家族と共有(CSV)」を使います。

| 操作 | 内容 |
| --- | --- |
| CSVエクスポート | 次・品名・チェック・保管場所をCSVで書き出し(Excel/スプレッドシートで編集可) |
| CSVインポート(マージ) | 同じ次・同じ品名は更新し、新しい防災用品だけ追加。自分の防災用品は消えない |
| CSVインポート(上書き) | CSVに含まれる次のリストを、CSVの内容にそろえる |
| JSONバックアップ | 説明文なども含めた完全なバックアップ(自分用・端末の引っ越し用) |

CSVの列は `次, 品名, チェック(済/未), 保管場所(複数は ; 区切り)` です。
品名が空の行は、保管場所だけを登録する行です。

> **ご注意**: ブラウザのデータを消去すると中身も消えます。iPhoneのSafariでは、ホーム画面に追加していない
> サイトのデータが、しばらく使わないと自動で削除されることがあります。**ホーム画面に追加して使い、
> ときどきバックアップを取る**ことをおすすめします。

## 使い方(スマホ)

1. 公開URLをブラウザで開く
2. iPhone: 共有ボタン →「ホーム画面に追加」/ Android: メニュー →「ホーム画面に追加(アプリをインストール)」

## 公開方法(GitHub Pages)

1. このリポジトリの **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」、Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/bousailist/` で公開される

家族は発行されたURLを開くだけで使えます(GitHubアカウントは不要)。

## バージョン管理

アプリのバージョンは設定画面の一番下に表示されます。更新するときは次の3か所を同じ番号にそろえます。

| 場所 | 内容 |
| --- | --- |
| `index.html` の `APP_VERSION` / `APP_VERSION_DATE` | 設定画面に表示される番号 |
| `service-worker.js` の `CACHE_NAME` | `bousai-list-<番号>`(古いキャッシュを破棄) |
| `index.html` の `RELEASE_NOTES` | アプリ内のお知らせ文(新しい版を上に追加) |
| 下の更新履歴 | 変更内容 |

## 構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体(HTML・CSS・JavaScriptを1ファイルにまとめたもの) |
| `manifest.json` | ホーム画面に追加したときの名前・アイコン設定 |
| `service-worker.js` | オフライン対応。ページは通信できるときは常に最新版を取得 |
| `icons/` | アプリアイコン |

ローカルで確認するには、このフォルダで `python3 -m http.server` を実行して `http://localhost:8000/` を開きます
(service workerはファイルを直接開く方法では動きません)。
